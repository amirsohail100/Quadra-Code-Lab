Quadra Code Lab

An offline practice lab for Python, C++, DSA and SQL. Questions, tests and answers on your own machine. Solve in your own editor.

1. Pick a track

Each track has its own page, categories and Easy / Medium / Hard levels.

2. Solve in VS Code

Read the question (or have it read aloud), write your solution in your editor.

3. Check and compare

Download the test script, run it, then open the closed-by-default reference answer to compare.

Progress is stored in this browser only. Works fully offline.
